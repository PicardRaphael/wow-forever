- 70450 : 229 tests rouges, dont 8 vrais défauts ; le reste rattaché à une version figée
  (`tasks/70450-corrections.md`). 70291 : 32 rouges et 87 en erreur (`tasks/70291-corrections.md`).
- Versions figées des tests : `SEED_VERSION`, `PREVIOUS_VERSION` (70009), `CLASS_FIXTURE_VERSION` (70124),
  `RANK_VALUES_VERSION` (70245), `PRE_70450_VERSION` (70374) ; une constante de plus à chaque version qui change des
  valeurs. 103 signatures de test dans 41 fichiers prennent une fixture figée ; 85 fichiers (1 159 tests collectés)
  citent une de ces constantes ; 88 fichiers lisent `game_data` à la version installée : ce sont eux qui sont exposés
  au prochain patch. 138 fichiers écrivent une version en dur.

  - marqueurs `model` : une sous-chaîne anglaise de la description du client choisit le sens d'un talent
    (`talent_models`) ; 11 branches du moteur en dépendent ; un texte qui ne correspond plus garde l'ancien sens
    **sans rien signaler** ;
  - `rank_variables` selon la forme de l'infobulle (une forme nouvelle bloque le décodage) ; `target_auras`,
    `racial_values`, `new_spells` écrits à la main ;
  - `confirmed_changes.json` (104 changements à 70450) : toute valeur non confirmée refuse l'installation ;
  - `origins.json` de 70450 : 79 règles `manuel` ;
  - « 70450 » écrit dans 25 fichiers de `forever/` (84 lignes).

## 5. La veille (`update.py`, `replay.py`)
Archivage, clone dédié, version publiée, attente du `DBCache.bin`, téléchargement, décodage, puis vérification,
plan et installation dans une copie, report des valeurs faites à la main, preuve d'entrées par moteur et rejeu des
16 cas de builds du Mage. Verdict : écrire, attente ou bloqué ; **attente dès que les entrées d'un moteur qui calcule
changent**, donc à chaque version qui touche le Mage. Échecs connus : installation refusée qui fait tourner
`verify` sans la nouvelle version (70291) ; pas de rejeu quand un talent ou un sort est ajouté (70450, rejeu fait à la
main) ; attentes réseau, colonnes inconnues, dispositions manquantes, correctifs non lus.
