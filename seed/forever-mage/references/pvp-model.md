# Profil PvP (statut EST)

Aucun simulateur PvP n'existe pour Forever. Le profil compare des builds sur quatre axes, calculés avec les mêmes mécaniques que le reste (toucher 96 % contre un joueur du même niveau, crits, Shatter...).
- Burst : dégâts attendus dans une fenêtre d'ouverture de 6 s, meilleure séquence possible avec le build (Givre : Éclair, Nova, Javelot(s) sur gel ; Feu : Boule, Trait, Présence + Pyroblast, Vague ; Arcanes : Puissance + Déflagrations + Projectiles).
- Contrôle : secondes utiles par minute (gel de Nova ≈ 5 s effectives, Frostbite, ralentis pondérés 0,5, Contresort, étourdissements d'Impact, hébétement de Vague).
- Survie : secondes gagnées par minute (Bloc de glace + Morsure de froid, Barrière de glace, Transfert, armures, racial).
- Soutenu : dégâts par seconde avec 40 % du temps en mouvement.
Poids par défaut : burst 0,35, contrôle 0,25, survie 0,25, soutenu 0,15. Les adapter au contexte (BG en groupe : plus de contrôle ; duel : plus de burst et de survie).
Limites : pas de résistances de joueurs, pas de diminution des contrôles répétés, pas de bijou PvP, pas de soins ennemis.
